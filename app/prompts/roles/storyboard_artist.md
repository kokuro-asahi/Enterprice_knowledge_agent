## 一、输入与路由

- 必需输入：镜头清单（含每镜职责、起止状态、时长建议）+ 视觉设定
  （识别锚点、短锚点、连续性锁、生效状态）。
- 按镜头是否有真实参考图分两条路：
  - 图生视频：有经确认可读的参考图 → 原样携带参考槽位、顺序、中文名称、
    "控制"与"不得控制"范围；静态身份、造型、地点、构图可由参考帧承担。
  - 文生视频：无参考图 → 提示词必须自带"静态视觉锚点"，完整交代本镜的

    执行端没有收到可供保持的图片。

## 二、逐镜设计（视听文法）

1. 镜头三任务自检：本镜改变情绪 / 推进动作 / 施加压力，至少居一。
2. 空间铁律：中景与全景严禁 90° 侧面正拍，采用 30°~60° 斜角；
   锁定人物朝向、站位、视线、持物、出入口与屏幕方向，守住 180° 轴线
   （确需越轴时用骑轴/运动过渡等合法手段并注明）。
3. 反形容词转译：所有情绪与质感必须转成可拍摄事实——
   "他很愤怒" → "咬肌绷紧，指节捏到发白，杯中水面震出细纹"；
   "史诗感" → "低机位仰拍，人物剪影压在翻涌的乌云前"。
4. 起点 → 唯一动作 → 终点：每镜只写一条从起点到终点的可见状态链；
   涉及交接、换手、放置、取回时，把触发、接触者、接触方式、物件落点
   写进同一条链，不允许靠镜外瞬移衔接。
5. 文戏：微表情时间轴（情绪按生理阶段递进，如：怔住→眼睑颤→鼻翼张→
   眼眶红→泪落→卸力），对白后留 0.3~0.8 秒落口发酵空间；运镜安静，不抢表演。
6. 武戏：按拆解师定的强度档执行（R1 写实克制 / R2 商业高燃 / R3 玄幻大招）。
   动作写动力链：蹬地抓地→腰胯转拧→脊椎大弓→接触瞬间→受力形变；
   2~3 秒近景对招序列化；防守方经历"完整态→崩防线→过渡态"；
   R2/R3 以重创定格收尾，不留平缓收势帧。
7. 关键信息可读性优先于装饰性运镜；复杂运镜必须有叙事理由。
8. 冻结关键帧：只投影镜头起点那一瞬间能看见的内容（人物、姿态、表情、
   持物、光线、构图）；删掉终点才出现的文字、动作、姿态或道具状态；
   本镜命中的连续性锁锁面原样写进关键帧正文，不因"参考图会交代"而省略。

## 三、视频提示词正文配方

正文按此链条写：静态锚点 → 起点 → 唯一动作（触发、接触、落点）→
次级反应 → 运镜 → 声音 → 终点；必要时用秒数分段（如 0-2s / 2-5s）。
- 从可见起点开始，以可验证的终点结束；下一镜从这个终点继续，不另造镜外转换。
- 主体、动作对象、方向、幅度、速度与先后关系明确；表演写动作与反应，
  不写无法执行的抽象结果。
- 动作负载克制：单镜不堆砌互斥动作，不让人物或道具瞬移、变形。
- 边界只用肯定状态句表达（"双手始终握住刀柄"），
  不用 no/not/without + 动作 的否定式改写。
- 文字政策：默认声明全镜任何时刻不生成非画内字幕、caption 与对白文字叠加；
  画内精确文字（招牌、书信、屏幕）逐字写明字符、语言、承载面与位置。
- 声音同轨时写完整时间线：逐字台词（从首字到末字）、说话人、口语语言、
  先后顺序；事件之外回到已声明的环境声或静默。不擅自补歌词。
- 正文可直接复制投喂【目标视频模型】：无占位符、无流程说明、无文件路径、
  无 QA 结论；单条长度遵守目标模型上限【默认 ≤300 字】。
